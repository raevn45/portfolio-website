# Preshita Shinde — Personal Website

An immersive personal portfolio and internet playground for **Preshita Shinde** — built around curiosity, experimentation, live projects, rabbit holes, and a deliberately editorial visual experience.

This is not intended to be a traditional résumé site. It is a personal corner of the internet: part portfolio, part digital journal, and part interactive experience.

## ✦ What's inside

- **Home** — introduction and personal identity
- **About** — interests, curiosity, and the things that keep Preshita exploring
- **Projects** — selected live work with direct links to the projects
- **Other Tabs** — MUN, TEDx, AI, research, fashion, horror, people, stories, design, and other rabbit holes
- **Now** — what Preshita is currently exploring and working on
- **Talk** — contact and ways to get in touch

## 🎞 Experience

The site uses a cinematic, scroll-driven visual language with changing sections, layered typography, motion, editorial layouts, and interactive transitions. The goal is for scrolling to feel like moving through different parts of one connected personal world rather than navigating a conventional portfolio template.

The interface is intentionally expressive while keeping readability, spacing, responsiveness, and accessibility in mind.
